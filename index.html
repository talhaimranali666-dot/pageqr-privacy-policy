PageQR Privacy Policy

Last updated: September 20, 2026

PageQR — Web Page to QR is a Chrome extension that generates QR codes from the webpage currently open in the user's Chrome browser.

Information We Process

PageQR accesses the URL and title of the active browser tab when the user opens or uses the extension. This information is used solely to generate and display a QR code for the current webpage.

Local Processing

PageQR generates QR codes locally within the browser. The webpage URL is not sent to a remote QR-code generation service.

Data Collection

PageQR does not collect, sell, or share personal information, browsing history, website content, authentication information, financial information, health information, location information, or personal communications.

PageQR does not maintain a database of the webpages users visit.

Stored Preferences

If enabled in the extension, PageQR may use Chrome's local storage functionality to remember non-personal preferences, such as the selected theme or QR-code size.

Third Parties

PageQR does not sell or transfer user data to third parties.

Remote Services

The core QR-generation functionality does not require a remote server or external QR-generation service.

Children's Privacy

PageQR does not knowingly collect personal information from children or other users.

Changes to This Policy

If the privacy practices of PageQR change, this privacy policy will be updated accordingly.

Contact

For questions regarding this privacy policy or PageQR, please use the support contact provided on the Chrome Web Store listing.
